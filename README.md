# 식단 · 공복 표 체크

임신 중 체중·붓기 관리를 하면서 하루 식단과 1시간 단위 공복 참기 시간을 기록하는 모바일 웹앱입니다.

- 공복 체크: 요일 × 시간 표(07시~23시)를 눌러 스탬프처럼 체크
- 식단 기록: 아침/점심/저녁/간식 + 칼로리·메모, 하루 총칼로리 합산
- 기록은 기기 브라우저(localStorage)에 날짜별로 자동 저장됩니다. 서버로 전송되지 않습니다.

## 사용법
아이폰 Safari로 https://armdaunrim-hue.github.io/diet-tracker/ 를 열고, 공유 버튼 → **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.
(시크릿 모드에서는 저장되지 않으니 일반 탭으로 열어 주세요.)
